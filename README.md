# Memory Game

Игра на запоминание: 16 карточек рубашкой вверх, 8 пар изображений.
Цель — найти все пары за минимальное число ходов.

## Описание приложения

- Игровое поле 16 карточек (8 пар одинаковых изображений), перемешанных случайно.
- Игрок открывает по две карточки за ход:
  - совпавшие остаются открытыми,
  - несовпавшие закрываются через секунду.
- Счётчики ходов и найденных пар обновляются в реальном времени.
- После победы открывается модальное окно с итоговым числом ходов.
- Таблица лидеров хранит 10 лучших результатов в `localStorage`.
- Интерфейс на английском языке, доступен с клавиатуры.

## Технологии

- Vanilla JavaScript (ES-модули), без сторонних библиотек и фреймворков.
- Чистый CSS (3D-переворот карточек).
- Vite как сборщик и dev-сервер.
